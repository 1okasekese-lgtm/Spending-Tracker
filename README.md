This is a simple Android app that shows you your detailed weekly budget, 
shows u how much money you have allocated for each item and how much you spent,
on each particular day.
It features a Splash Screen, which smoothly transitions into the Main Screen, 
where you'll be met with three buttons, for viewing spending, calculating what you have left and an exit button to exit the app.
Viewing and Calculating screens both feature buttons which leads back into the main screen.
